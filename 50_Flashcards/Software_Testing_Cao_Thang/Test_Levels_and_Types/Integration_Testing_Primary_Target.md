Mục tiêu cốt lõi của cấp độ Kiểm thử tích hợp (Integration Testing) là gì?

---

- **Mục tiêu**: Kiểm tra sự tương tác, truyền nhận dữ liệu và phát hiện lỗi tại các điểm giao tiếp (interfaces) giữa các module/đơn vị phần mềm đã kết nối với nhau.

---

Extra: Dù từng module Unit Test đều pass độc lập, Integration Testing vẫn có thể thất bại do sai lệch kiểu dữ liệu, định dạng payload API hoặc sai giả định giao thức truyền thông.
