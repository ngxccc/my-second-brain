What is the terminology distinction between **Stateful** and **Stateless** architecture?

---

- **Formula**: `Stateless`: `inherently stateless` (HTTP protocol); `Stateful`: `maintain session state` (Session / Cookies)
- **Core Usage**: `Stateless` nghĩa là mỗi request độc lập không lưu state trên server, `Stateful` nghĩa là server lưu session/state giữa các request.

---

Extra:

- Usage: - `Stateless API` / `Stateful Session`
- Examples:
  - _`REST APIs are designed to be stateless.`_ (Các REST API được thiết kế theo dạng vô trạng thái.)
  - _`Session state makes the web application stateful.`_ (Trạng thái session khiến ứng dụng web trở nên có trạng thái.)
