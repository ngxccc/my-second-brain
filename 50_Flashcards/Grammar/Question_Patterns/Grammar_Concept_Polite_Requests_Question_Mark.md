What is the punctuation rule for polite request questions (**Could you...?

---

- **Formula**: `Could / Would / Can + Subject + V-bare + ...?`
- **Core Usage**: - Các câu đề nghị/yêu cầu lịch sự bắt đầu bằng Động từ khuyết thiếu (`Could you`, `Would you`) về mặt ngữ pháp là C...

---

Extra:

- Usage: - ❌ `Could you edit the file.`
  - ✅ `Could you edit the file?`
- Examples:
  - _`Could you refactor this function to improve readability?`_ (Bạn có thể refactor hàm này để tăng độ đọc được không?)
  - _`Would you mind checking the build log?`_ (Bạn có phiền kiểm tra log build không?)
