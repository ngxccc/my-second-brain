What is the definition, type, pronunciation, and usage of the term **value type**?

---

- **Type**: Noun Phrase
- **Pronunciation**: /ˈvæl.juː ˌtaɪp/
- **Meaning**: A data type whose values are copied completely when assigned to a variable or passed into a function call (kiểu dữ liệu truyền theo giá trị / bản sao).
- **Collocations**:
  - `treat arrays as value types`
  - `value type semantics`
  - `value type vs reference type`
- **Concrete Examples**:
  - _In Go, arrays and structs are **value types**, meaning passing them duplicates their memory contents._
