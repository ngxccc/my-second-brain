What is the definition, type, pronunciation, and usage of the term **value semantics**?

---

- **Type**: Noun Phrase
- **Pronunciation**: /ˈvæl.juː sɪˌmæn.tɪks/
- **Meaning**: A programming model where assigning or passing an entity creates an independent, isolated copy of its data, guaranteeing that mutations do not affect the original source (ngữ nghĩa truyền theo giá trị / bản sao độc lập).
- **Collocations**:
  - `enforce value semantics` (áp dụng ngữ nghĩa giá trị)
  - `pointer semantics vs value semantics` (ngữ nghĩa con trỏ đối chiếu với ngữ nghĩa giá trị)
  - `safe concurrency via value semantics` (an toàn đồng thời nhờ ngữ nghĩa giá trị)
- **Concrete Examples**:
  - _Go primitives and structs use **value semantics** by default, copying data across function boundaries._
  - _Emphasizing **value semantics** makes concurrent programs inherently safer by eliminating shared mutable state._
