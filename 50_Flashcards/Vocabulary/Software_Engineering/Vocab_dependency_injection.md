What is the definition, type, pronunciation, and usage of the term **dependency injection**?

---

- **Type**: Noun Phrase
- **Pronunciation**: /dɪˌpen.dən.si ɪnˈdʒek.ʃən/
- **Meaning**: A software design pattern where an object receives its collaborating dependencies from an external source rather than instantiating them internally (tiêm phụ thuộc).
- **Collocations**:
  - `constructor dependency injection` (tiêm phụ thuộc thông qua hàm khởi tạo)
  - `dependency injection container` (thùng chứa quản lý tiêm phụ thuộc)
  - `facilitate testing with dependency injection` (hỗ trợ viết unit test bằng dependency injection)
- **Concrete Examples**:
  - _Using constructor **dependency injection** makes it straightforward to mock database clients in unit tests._
  - _In Go, **dependency injection** is typically achieved by passing interfaces directly to constructor functions._
