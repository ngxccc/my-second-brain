What is the Word Family Matrix, types, pronunciation, and usage of **overhead**?

---

- **Type**: Noun / Adjective / Adverb
- **Pronunciation**: /ˈoʊ.vɚ.hed/
- **Meaning**: The indirect or excess computing resources (CPU cycles, memory, network latency) consumed by system infrastructure or abstractions beyond the core task (chi phí phụ trội, tài nguyên tiêu hao thêm).
- **Collocations**:
  - `memory overhead` (chi phí phụ trội về bộ nhớ)
  - `computational overhead` (tải tính toán phụ trội)
  - `minimize runtime overhead` (giảm thiểu chi phí phụ trợ khi chạy chương trình)
- **Concrete Examples**:
  - _Passing large structs by value creates unnecessary copy **overhead** on the CPU cache._
  - _Using reflection in Go introduces measurable runtime **overhead** compared to direct interface calls._
