What is the definition, type, pronunciation, and usage of the term **runtime exceptions and refactoring bottlenecks**?

---

- **Type**: Complex Technical Noun Phrase
- **Pronunciation**: /ˈrʌn.taɪm ɪkˈsep.ʃənz ænd ˌriːˈfæk.tɚ.ɪŋ ˈbɑː.t̬əl.nekz/
- **Meaning**: The dual engineering risks of unexpected program crashes during execution paired with architectural roadblocks that impede safe code modification (ngoại lệ khi chạy và điểm nghẽn tái cấu trúc).
- **Collocations**:
  - `mitigate runtime exceptions and refactoring bottlenecks` (giảm thiểu lỗi runtime và điểm nghẽn tái cấu trúc)
  - `tackle refactoring bottlenecks` (giải quyết điểm nghẽn tái cấu trúc)
  - `prevent critical runtime exceptions` (ngăn chặn ngoại lệ runtime nghiêm trọng)
- **Concrete Examples**:
  - _Adopting static typing in Go prevents common **runtime exceptions and refactoring bottlenecks**._
  - _Tightly coupled dependencies create **runtime exceptions and refactoring bottlenecks** across microservices._
