Using constructor ~~dependency injection~~ makes it straightforward to mock database clients in unit tests.

---

Extra:

- Meaning: A software design pattern where an object receives its collaborating dependencies from an external source rather than instantiating them int.
- Pronunciation: /dɪˌpen.dən.si ɪnˈdʒek.ʃən/
- Collocations:
  - `constructor dependency injection` (tiêm phụ thuộc thông qua hàm khởi tạo)
  - `dependency injection container` (thùng chứa quản lý tiêm phụ thuộc)
  - `facilitate testing with dependency injection` (hỗ trợ viết unit test bằng dependency injection)
