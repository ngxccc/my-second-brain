What is the core meaning and primary technical collocation of **staged changes**?

---

- **Meaning**: File modifications explicitly added to Git's index staging area via `git add` that are prepared to be recorded in the next commit (các thay đổi đã đưa vào vùng...
- **Primary Collocation**: `review staged changes` / `commit staged changes`

---

Extra:
- Pronunciation: /ˌsteɪdʒd ˈtʃeɪn.dʒɪz/
- Type: Noun Phrase
- Collocations:
  - `review staged changes` (kiểm tra các thay đổi đã stage)
  - `commit staged changes` (ghi commit các thay đổi đã stage)
  - `unstage staged changes` (rút các thay đổi ra khỏi vùng stage)
- Examples:
  - _Always run `git diff --cached` to inspect your **staged changes** before writing the commit message._
  - _The pre-commit hook runs automated linters exclusively against **staged changes**._
