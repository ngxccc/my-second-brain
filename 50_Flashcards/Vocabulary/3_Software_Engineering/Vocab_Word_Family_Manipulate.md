To control, modify, or transform digital information, engineers must ~~manipulate~~ electronic data.

---

Extra:

- Meaning: Control, modify, or transform data or information systematically (xử lý, biến đổi, thao tác trên dữ liệu điện tử).
- Pronunciation: /məˈnɪp.jə.leɪt/
- Word Family:
  - **Verb**: `manipulate` (/məˈnɪp.jə.leɪt/ - thao tác, biến đổi, xử lý dữ liệu)
  - **Noun**: `manipulation` (/məˌnɪp.jəˈleɪ.ʃən/ - thao tác xử lý dữ liệu, sự thao túng) / `manipulator` (/məˈnɪp.jə.leɪ.tər/ - bộ thao tác, đối tượng xử lý)
  - **Adjective**: `manipulative` (/məˈnɪp.jə.lə.tɪv/ - mang tính thao túng hoặc thao tác)
  - **Adverb**: `manipulatively` (/məˈnɪp.jə.lə.tɪv.li/ - một cách thao túng)
- Collocations:
  - `manipulate data / string / array` (thao tác, biến đổi dữ liệu / chuỗi / mảng)
  - `data manipulation language (DML)` (ngôn ngữ thao tác dữ liệu, e.g., SQL INSERT/UPDATE/DELETE)
  - `DOM manipulation` (thao tác trực tiếp trên DOM tree trong frontend)
  - `directly manipulate memory` (thao tác trực tiếp trên vùng nhớ / con trỏ)
- Examples:
  - `The pipeline manipulates electronic data before writing it to cold storage.` (Đường ống biến đổi dữ liệu điện tử trước khi ghi vào kho lưu trữ nguội.)
  - `Python provides powerful built-in libraries to manipulate large JSON payloads efficiently.` (Python cung cấp các thư viện tích hợp mạnh mẽ để xử lý các gói dữ liệu JSON lớn một cách hiệu quả.)
