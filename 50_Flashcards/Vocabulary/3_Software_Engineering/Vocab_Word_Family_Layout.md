What is the core meaning and primary technical collocation of **layout**?

---

- **Meaning**: The arrangement or visual structure of text, UI components, or hardware (bố cục, cách sắp xếp cấu trúc giao diện hoặc văn bản).
- **Primary Collocation**: `visual layout` / `bracket layout`

---

Extra:
- Pronunciation: /ˈleɪ.aʊt/
- Type: Noun / Phrasal Verb (Word Family)
- Word Family:
  - **Verb**: `lay out` (/leɪ aʊt/ - sắp đặt, bố trí, trình bày)
  - **Noun**: `layout` (/ˈleɪ.aʊt/ - bố cục, cách trình bày)
  - **Adjective**: `laid-out` (/leɪd aʊt/ - được bố trí, được trình bày rõ ràng)
  - **Adverb**: `layout-wise` (/ˈleɪ.aʊt.waɪz/ - xét về mặt bố cục / giao diện)
- Collocations:
  - `visual layout` (bố cục trực quan)
  - `bracket layout` (bố cục dạng dấu ngoặc nhọn)
  - `UI / responsive layout` (bố cục giao diện co giãn)
- Examples:
  - _Verb: The design engineer will **lay out** the formula using clear brackets._
  - _Noun: The new **layout** makes the grammar pattern easier to memorize._
  - _Adjective: The well-**laid-out** documentation reduced onboarding time._
  - _Adverb: The application is clean **layout-wise**, but lacks responsive breakpoints._
