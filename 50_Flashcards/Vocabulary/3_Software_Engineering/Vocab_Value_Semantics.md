Go primitives and structs use ~~value semantics~~ by default, copying data across function boundaries.

---

Extra:

- Meaning: A programming model where assigning or passing an entity creates an independent, isolated copy of its data, guaranteeing that mutations do not affect the origin.
- Pronunciation: /ˈvæl.juː sɪˌmæn.tɪks/
- Collocations:
  - `enforce value semantics` (áp dụng ngữ nghĩa giá trị)
  - `pointer semantics vs value semantics` (ngữ nghĩa con trỏ đối chiếu với ngữ nghĩa giá trị)
  - `safe concurrency via value semantics` (an toàn đồng thời nhờ ngữ nghĩa giá trị)
