What is the core meaning and primary technical collocation of **build**?

---

- **Meaning**: To construct, assemble, or compile a software application or system (xây dựng, biên dịch).
- **Primary Collocation**: `build pipeline` / `production build`

---

Extra:
- Pronunciation: /bɪld/
- Type: Verb / Noun (Word Family)
- Word Family:
  - **Verb**: `build` (/bɪld/ - xây dựng, biên dịch)
  - **Noun**: `build` (/bɪld/ - bản build / sự biên dịch) / `builder` (/ˈbɪl.dər/ - người/mẫu thiết kế builder)
  - **Adjective**: `buildable` (/ˈbɪl.də.bəl/ - có thể biên dịch được)
  - **Adverb**: `N/A`
- Collocations:
  - `build pipeline` (tuyến biên dịch/phát triển)
  - `production build` (bản build production)
- Examples:
  - _Verb: We **build** high-throughput web APIs using Go._
  - _Noun: The CI/CD **build** completed without errors._
  - _Noun: Apply the **builder** pattern for complex object creation._
