What is the Word Family Matrix, types, pronunciation, and usage of **mutate**?

---

- **Type**: Verb (Word Family)
- **Pronunciation**: /mjuːˈteɪt/
- **Meaning**: To change or alter form, qualities, or state; in programming: to modify the state or values of a data structure in-place (thay đổi, biến đổi trạng thái dữ liệu).
- **Word Family**:
  - **Verb**: `mutate` (/mjuːˈteɪt/ - thay đổi trạng thái, biến đổi)
  - **Noun**: `mutation` (/mjuːˈteɪ.ʃən/ - sự biến đổi, thao tác ghi dữ liệu) / `mutator` (/ˈmjuː.teɪ.t̬ɚ/ - phương thức biến đổi dữ liệu)
  - **Adjective**: `mutable` (/ˈmjuː.t̬ə.bəl/ - có thể thay đổi) / `immutable` (/ɪˈmjuː.t̬ə.bəl/ - bất biến)
  - **Adverb**: `mutably` (/ˈmjuː.t̬ə.bli/ - một cách có thể biến đổi)
- **Collocations**:
  - `mutate state in-place` (thay đổi trạng thái trực tiếp tại chỗ)
  - `prevent unintended mutations` (ngăn chặn các biến đổi trạng thái ngoài ý muốn)
  - `mutable vs immutable data structures` (cấu trúc dữ liệu có thể biến đổi đối chiếu với bất biến)
- **Concrete Examples**:
  - _Verb: Modifying slice elements will **mutate** the underlying array visible to other slice views._
  - _Adjective: Functional programming favors **immutable** data structures to guarantee thread safety._
