What is the core meaning and primary technical collocation of **memory address**?

---

- **Meaning**: A unique numerical hexadecimal identifier for a specific physical or virtual memory byte location where data is stored in RAM (địa chỉ ô nhớ).
- **Primary Collocation**: `point to a memory address` / `print the memory address`

---

Extra:
- Pronunciation: /ˈmem.ər.i əˌdres/
- Type: Noun Phrase
- Collocations:
  - `point to a memory address` (trỏ đến một địa chỉ ô nhớ)
  - `print the memory address` (in ra địa chỉ ô nhớ, ví dụ &x)
  - `valid memory address` (địa chỉ ô nhớ hợp lệ)
- Examples:
  - _A pointer variable stores the **memory address** of another variable rather than the data value itself._
  - _Dereferencing an invalid **memory address** like `0x0` causes an immediate null pointer panic._
