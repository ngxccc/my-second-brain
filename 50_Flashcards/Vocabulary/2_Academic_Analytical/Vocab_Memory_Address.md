A pointer variable stores the ~~memory address~~ of another variable rather than the data value itself.

---

Extra:

- Meaning: A unique numerical hexadecimal identifier for a specific physical or virtual memory byte location where data is stored in RAM (địa chỉ ô nhớ).
- Pronunciation: /ˈmem.ər.i əˌdres/
- Collocations:
  - `point to a memory address` (trỏ đến một địa chỉ ô nhớ)
  - `print the memory address` (in ra địa chỉ ô nhớ, ví dụ &x)
  - `valid memory address` (địa chỉ ô nhớ hợp lệ)
