What is the core meaning and primary technical collocation of **ergonomics**?

---

- **Meaning**: The scientific study of people and their working conditions, especially done in order to improve effectiveness and ease of use
- **Primary Collocation**: `cognitive ergonomics` / `developer ergonomics`

---

Extra:
- Pronunciation: /ˌɜː.ɡəˈnɒm.ɪks/
- Type: Noun (Word Family)
- Word Family:
  - **Verb**: `N/A`
  - **Noun**: `ergonomics` (/ˌɜː.ɡəˈnɒm.ɪks/ - công thái học)
  - **Adjective**: `ergonomic` (/ˌɜː.ɡəˈnɒm.ɪk/ - mang tính công thái học, thuận tiện trực quan)
  - **Adverb**: `ergonomically` (/ˌɜː.ɡəˈnɒm.ɪ.kəl.i/ - theo cách công thái học)
- Collocations:
  - `cognitive ergonomics` (công thái học nhận thức / giảm tải thao tác não bộ)
  - `developer ergonomics` (sự tiện dụng và trực quan cho lập trình viên)
  - `ergonomic API design` (thiết kế giao diện API trực quan, dễ dùng)
- Examples:
  - _Noun: Plaintext JSON offers superior **developer ergonomics** for LLM agents compared to binary SQLite files._
  - _Adjective: The CLI provides an **ergonomic** interface for interactive debugging._
  - _Adverb: The software suite is **ergonomically** designed to minimize repetitive strain._
