What is the core meaning and primary technical collocation of **compile time analysis**?

---

- **Meaning**: Code inspection and optimization performed by the compiler before program execution begins, catching bugs and deciding memory placement (phân tích tại thời điểm...
- **Primary Collocation**: `perform compile time analysis` / `static compile time analysis`

---

Extra:
- Pronunciation: /kəmˈpaɪl taɪm əˌnæl.ə.sɪs/
- Type: Noun Phrase
- Collocations:
  - `perform compile time analysis` (thực hiện phân tích lúc biên dịch)
  - `static compile time analysis` (phân tích tĩnh tại thời điểm biên dịch)
  - `detect errors via compile time analysis` (phát hiện lỗi nhờ phân tích lúc biên dịch)
- Examples:
  - _Go performs **compile time analysis** to determine whether variables should escape to the heap._
  - _Rust relies heavily on **compile time analysis** to guarantee thread safety without a garbage collector._
