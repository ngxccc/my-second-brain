What is the core meaning and primary technical collocation of **ingest**?

---

- **Meaning**: To absorb, gather, or import data into a system for processing (nạp/thu thập dữ liệu).
- **Primary Collocation**: `ingest data` / `data ingestion pipeline`

---

Extra:
- Pronunciation: /ɪnˈdʒest/
- Type: Verb (Word Family)
- Word Family:
  - **Verb**: `ingest` (/ɪnˈdʒest/ - thu thập/nạp dữ liệu)
  - **Noun**: `ingestion` (/ɪnˈdʒes.tʃən/ - quá trình thu thập/nạp dữ liệu)
  - **Adjective**: `ingestive` (/ɪnˈdʒes.tɪv/ - thuộc về nạp/thu thập)
  - **Adverb**: `N/A`
- Collocations:
  - `ingest data` (nạp/thu thập dữ liệu)
  - `data ingestion pipeline` (tuyến xử lý nạp dữ liệu)
- Examples:
  - _Verb: The pipeline must **ingest** millions of clickstream events per second._
  - _Noun: Automated data **ingestion** reduces real-time latency._
  - _Adjective: The architecture features an efficient data **ingestive** stage._
