Unlike heap objects that require garbage collector passes, stack allocations enjoy instant ~~stack frame cleanup~~.

---

Extra:

- Meaning: The automatic, zero-overhead process where a CPU rewinds its stack pointer to reclaim local variable space upon function return.
- Pronunciation: /ˈstæk freɪm ˈkliːn.ʌp/
- Collocations:
  - `instantaneous stack frame cleanup` (dọn dẹp khung ngăn xếp tức thời)
  - `rely on stack frame cleanup` (dựa vào cơ chế dọn dẹp khung stack)
  - `zero-cost stack frame cleanup` (thu hồi stack frame không tốn chi phí GC)
